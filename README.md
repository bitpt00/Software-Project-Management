# 软件项目管理课程资料库

本仓库用于组织《软件项目管理》课程的教学资料、课堂任务和贯穿项目过程成果。

## 贯穿项目

- 项目名称：校园实验室预约与审批系统
- 技术栈：Python、Flask、SQLite
- 当前教学基线：学生已完成 D00—D16，并提交到各自的 Gitee 仓库
- 后续主线：以现有系统为基线，开展一轮受控改进，依次完成立项、需求、计划、估算、进度、质量、风险、变更、发布和验收

## 目录

- `references/textbook/`：教材章节索引与课程映射，不存放商业教材全文
- `teaching/`：各次课教学思路、实践任务和检查要求

## 教材说明

课程教材为朱少民等编著的《软件项目管理（第3版·微课版）》。完整教材属于受版权保护的商业出版物，不放入公开仓库；本仓库仅保存章节目录、页码索引、教学提炼和课程适配材料。
